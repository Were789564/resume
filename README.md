# 石哲綸｜個人履歷

純 HTML / CSS 靜態網頁，無需安裝套件或建置。直接開啟 `index.html` 即可瀏覽。

## 檔案

- `index.html`：履歷內容與導覽。
- `styles.css`：桌面、手機與列印樣式。
- `favicon.svg`：網站圖示。
- `assets/profile.jpg`：使用者提供的生活照片，網頁以 CSS 調整顯示範圍。
- `assets/resume.jpg`：原始履歷圖片，目前網頁未使用。

## GitHub Pages

如果把此資料夾的內容放在獨立 repository 的根目錄，可在 GitHub 的 Settings → Pages 選擇 Deploy from a branch，再選擇所在分支與 `/ (root)`。如果保留 `lab1` 子資料夾並從 repository 根目錄發布，網址路徑為 `/lab1/`。本次僅建立本地檔案，尚未部署。
